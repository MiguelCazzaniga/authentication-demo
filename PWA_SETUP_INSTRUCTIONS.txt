# PWA SETUP INSTRUCTIONS - Authentication Demo
# Complete guide to start NGrok and set the app online

=========================================================================
🚀 COMPLETE SETUP GUIDE: NGROK + PWA ONLINE
=========================================================================

## STEP 1: START THE NEXT.JS PRODUCTION SERVER

1. Open PowerShell (Terminal 1)
2. Navigate to your project directory:
   cd "D:\USUARIO\Desktop\PWA\ejercicios_con_Nextjs\authentication-demo"

3. Build the application for production (if not already built):
   npm run build

4. Start the production server on port 3001:
   npm start -- -p 3001

Expected output:
   ▲ Next.js 16.0.1
   - Local:        http://localhost:3001
   - Network:      http://192.168.0.75:3001
   ✓ Starting...
   ✓ Ready in 1580ms

## STEP 2: START NGROK IN A NEW TERMINAL

1. Open a NEW PowerShell terminal (Terminal 2) - KEEP THE FIRST ONE RUNNING
2. Start ngrok to tunnel port 3001:
   ngrok http 3001

Expected output:
   ngrok
   
   Session Status                online
   Account                       Miguel Cazzaniga (Plan: Free)
   Version                       3.32.0
   Region                        South America (sa)
   Latency                       58ms
   Web Interface                 http://127.0.0.1:4040
   Forwarding                    https://paroicous-myrtie-methodically.ngrok-free.dev -> http://localhost:3001

## STEP 3: NOTE YOUR HTTPS URL

From the ngrok output, copy the "Forwarding" HTTPS URL:
   https://paroicous-myrtie-methodically.ngrok-free.dev

⚠️ IMPORTANT: Your URL will be different each time ngrok starts

## STEP 4: ACCESS YOUR PWA ONLINE

### Desktop (Chrome):
1. Visit your HTTPS URL in Chrome
2. Look for the install icon in the address bar (⊕ or download icon)
3. Click to install as PWA
4. The app will appear on your desktop/start menu

### Mobile Device:
1. Open Chrome on your phone
2. Visit the same HTTPS URL
3. Chrome will show "Add to Home Screen" option
4. Install and use as native app

## STEP 5: KEEP BOTH SERVICES RUNNING

⚠️ CRITICAL: Both terminals must stay running for online access

Terminal 1: Next.js server (port 3001) - DO NOT CLOSE
Terminal 2: NGrok tunnel (HTTPS forwarding) - DO NOT CLOSE

=========================================================================
🔧 TROUBLESHOOTING
=========================================================================

Problem: NGrok URL changes
Solution: Restart ngrok to get a new URL (this is normal with free plan)

Problem: Port 3001 already in use
Solution: Run "taskkill /f /im node.exe" then restart Next.js server

Problem: PWA not installing
Solution: 
- Ensure you're using the HTTPS ngrok URL, not localhost
- Make sure both services are running
- Try hard refresh (Ctrl+Shift+R) in Chrome

Problem: Authentication not working
Solution: 
- Check that Clerk keys are properly configured
- Verify HTTPS URL is being used
